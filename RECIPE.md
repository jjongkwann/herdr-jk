# Omarchy

The Omarchy desktop, rebuilt inside Herdr: flat, square, bordered tiles floating over a wallpaper. The sidebar shows every space and agent with its live status, the top bar shows the AI quota of the agents on screen, and a side panel holds your files, Git changes and the full commit graph. Closed tabs reopen in place with their agents back in their own conversations. Omarchy's themes, wallpapers, theme switcher and keys come with it, and the palette, Settings, keybindings list and mod manager all share the same square look.

## What you see

Top to bottom, left to right. Sizes are logical px at zoom 1. Colors below are the default `tokyo-night` theme; every color is a theme name, so the other 23 themes recolor everything.

- **Top bar** (`topbar`, 30px, `chrome` `#16161e`, drags the window):
  - **Left** (weight 1): a 2x2 grid menu icon in `accent` `#7aa2f7` (opens the palette), then the numbers 1..N, one per space. The active number is in `foreground` with a 2px `accent` underline. Others are `dim` `#565f89`, and a space with a blocked agent shows its number in `blocked` `#f7768e`. After a `│` separator come the current space name, the focused terminal's folder when it differs, its branch and `@machine` when remote.
  - **AI usage** (weight 2 between left and right at weight 1 each, so it centers on the window; content centered): one segment per agent provider, Claude, Codex and Antigravity first (see AI usage below), then the others visible in the current tab: the program icon, then each of its first two windows (5h and 7d for Claude and Codex) as its `dim` label, a 6px horizontal bar (70px wide alone, 48px for two, 32px for three or more) and its % ("5h ▬ 51%  7d ▬ 24%"). Segments are split by the bar's own `│` divider in `border`. Each Claude segment names its profile after the icon: the label `settings.json`'s optional `claude_labels` gives its folder (`{ "~/.claude": "Work" }`), else the organization in the profile's `.claude.json` (`~/.claude.json` for `~/.claude`, else `<dir>/.claude.json`) such as "Flexspring", "Personal" for a personal account's "<email>'s Organization", else the folder name after `.claude-`, capitalized. Each bar fills in its provider's brand color, taken from Herdr's program icons: Claude `#D97757`, Codex `#7A9DFF`, Copilot `#a371f7`. It turns amber `#ffb347` at 80% or more and red `#ff5d6c` at 95% or more. Agents without a usage API show "no usage API" in `dim`.
  - **Mic** (`voice`, 56px, `omarchy-voice`): a mic that starts and stops dictation and shows the recording time, red while recording. A 0px `browser-cmd` block holds `omarchy-browser`, which only takes commands.
  - **Right** (weight 1): five flat 30px square buttons: search, sidebar toggle, minimize, maximize/restore, close. Close turns `blocked` on hover.
- **Desk** (row, 8px padding and 8px gaps, the theme's wallpaper from `backgrounds/omarchy/<theme>/` shows through):
  - **Sidebar** (243px column of three tiles, each `chrome` with a 2px `border` `#414868` frame and a 12px radius; inside each tile there is 10px of top padding like the footer, a 26px header, then the list 6px below it and 10px from the sides; header text starts 18px in to line up with row text, and header buttons sit 10px from the right):
    - **Spaces** (weight 1): header "spaces 8" and a square `+`. Rows are 26px, each with a 16px square number badge. The active row's badge is `accent` with `accent_foreground` text, the row has an 18% foreground fill and a 2px `accent` bar on its left. Other badges are `dim` numbers in a 1px `border` square. A branch name appears only when it fits whole. A space with an agent working, needing input or done ends in a 6px square in that status color. Rows have no fill at rest, only on hover and when active. A hovered row shows a × that closes the space; a space with a working or blocked agent needs a second click within 3s.
    - **Agents** (weight 1): header "agents 3", grouped "working 1", "idle 2". Rows are 26px with the program icon, the folder the agent is in now (its pane's live `cwd`, not the folder its space was started in), what the agent works on (its title, never just a program name like "Claude Code"), age, and a 7px square status dot. The focused row has an 18% fill and a 2px accent bar. Agents shown as Chat (parked behind a chat pane) are listed too. A hovered row shows a × that stops the agent; a working or blocked one needs a second click within 3s.
    - **Footer** (84px): a 2x2 grid of "Prefs" (Settings), "Keys" (Keybindings), "Mods" (layers icon, the mod manager) and "Add" (Add machine), full names in tooltips, with 10px top and bottom padding and no fill until hovered. On the folded rail it is a stack of the four icons, 136px tall; `omarchy-chrome` sets the height from the sidebar's width.
  - **Work column**:
    - **Tab strip** (36px tile): flat 240px cells with 1px `border` dividers. Each cell shows the agents' program icons, then what they work on (session title, else folder such as `~`, else branch; a shell's bare terminal address like `t4c` never counts as a title), a status word and a spinner while working. Program names like "Claude Code" or "Codex" never appear: the icons carry them. The active tab has the pane background and the same 2px `accent` frame as a focused pane. A tab's × shows when it's active or under the pointer, so any tab can be closed without selecting it first. A 36px `+` cell sits right after the last tab (Shepherdr's `new-menu-tasks` where it is installed, else Herdr's `new-menu`), and Files and Git toggles sit flush right, followed by Simulator (`herdr-sim`), Browser (`omarchy-browser`), Tasks and Artifacts buttons that show only while their mod is installed. Every item in the strip is a full-height flat cell with a 1px `border` divider; the open panel's toggle gets the same fill as the active tab.
    - **Panes**: 12px radius, 2px `border` frame and 2px `accent` frame when focused, 8px gaps, terminals at 70% opacity over the wallpaper with no pane fill, 30px header (`omarchy-pane`) that shows the program icon and what it works on (its title, else the folder), never the program name, terminal padding 12px. With Shepherdr's chat mod installed, Claude Code and Codex headers get a Chat | Terminal switch. Tab icons and pane header icons line up on the same left edge.
    - **Side panel** (475px, hidden until toggled): a stack of Files (`files`, the `files-plus` mod from jjongkwann/herdr-files-plus, installed separately), Git (a column `changes`: the switch row `git-switch` = `omarchy-changes` `{view:"switch"}`, 42px, with Changes, Graph, Review and PRs buttons, over a stack `git`: `changes-view` = `omarchy-changes` with diff and a Wrap header button, Fetch/Pull/Push/Stash/Pop row with ahead/behind counts, a branch list with `+ New branch…` (`git switch -c`), commit box and a solid `accent` Commit button; `git-graph` = `omarchy-changes` `{view:"graph"}`, the full commit graph with no title of its own; `review` = `reviewer`; `prs` = `pr-flow`). The file list and diff split at a draggable 8px gap (`shared("omarchy-changes.list")`, double-click fits the list again) browser notes (`omarchy-notes`), Shepherdr's Tasks (`tasks`: the task list, and a task thread from `chat` with `task-files`, `task-changes`, `task-pr` and `task-browser`) and Artifacts (`artifacts`), and the Simulator (`herdr-sim`).
- **Dialogs**: the palette (`ctrl-shift-p`, 660x450), Settings (`ctrl-,`, 970x690) Mods (`ctrl-shift-m`, 60% x 75%) and Themes (`super-ctrl-t`, 360x480) are square copies of Herdr's own screens.
- **Type**: the font from `settings.json` (the layout sets none). UI text is 11-13px, headings up to 16px.

## How it behaves

- **Agent status**: working shows the `working` `#e0af68` color, a pulsing square in the agents list and a spinner on the tab. Blocked (needs input) is `blocked` `#f7768e`, done is `done` `#9ece6a`, and idle is a hollow `dim` square. A tab's status is the most urgent of its agents.
- **Tabs with several agents**: the cell shows up to three distinct program icons side by side and the lead agent's work as its label. The tooltip lists each agent with its own status. A tab the person renamed keeps its name.
- **AI usage**: Claude, Codex and Antigravity always show when this machine has their login (Antigravity: the quota its statusline saved in `~/.gemini/antigravity-cli/quota-cache.json`, read without a network call), in that order; other agents in the focused tab follow them. Clicking it opens a popup with every window and its reset time, in 12-hour time ("resets in 2h 10m, at 4:30 PM"). Each provider refreshes when it first appears, then every 5 minutes.
  - **Live providers**: Claude (5h and 7d, plus model-scoped weekly limits), Codex (ChatGPT plan 5h and 7d) and Copilot (monthly premium requests). Antigravity shows its 5h and weekly windows as the agy statusline last saved them. On macOS, Claude's login is read from the Keychain (`Claude Code-credentials`, or `-<first 8 hex of sha256(config dir)>` for another `CLAUDE_CONFIG_DIR`), whichever of Keychain and file expires later.
  - **Mapped**: Pi and OpenCode reuse those three when their configured provider is Anthropic, OpenAI Codex or GitHub Copilot.
  - **Labelled only**: omp, devin, droid, kimi, kilo, hermes, qodercli, qwen, letta, cursor, mastracode, antigravity-cli and grok.
  - **Claude accounts**: when two Claude config directories exist (`~/.claude`, `~/.claude-personal`), the meter matches each terminal's `CLAUDE_CONFIG_DIR` to show the right account. When no terminal matches, `~/.claude` shows, and `~/.claude-personal` only if it has a login file.
- **Clicks**: a space number selects the space; the menu icon opens the palette; search opens the picker; the sidebar toggle collapses the sidebar to a 44px rail and back. A double-click on a tab renames it, dragging reorders, and right-click opens the tab menu.
- **Side panel**: remembered per space. In a space that isn't a Git repo the Changes button is hidden and a remembered Changes panel stays closed.
- **Hover**: controls get an 8% foreground fill and a 1px border at 25% foreground alpha, after Omarchy's shell control tokens.

Inside each, keys are grouped by type (Spaces, Tabs, Panes, Agents, Terminal, Git, Dialogs, Look, App, Other) with a plain-English label from `describe.js`; numbered runs fold into one row (`alt-1…9`), key chips and the raw action on the right. A click on a section or type heading folds it and the fold is remembered; a filter box, which also matches labels, shows every match; global keys the layout also binds read `overridden here`. The shown layout's own keys come first as one `accent` block (2px left bar, 5% tint, "THIS LAYOUT · CAME WITH OMARCHY" and a count, `accent` key chips). Opened with `super-k` (Omarchy's key) or the footer's Keys cell.

  - `omarchy-palette`, `omarchy-settings`: copies of Herdr's `frame/palette` and `frame/settings`, with `rounded(0)`.

Drawn as a full-window dialog (`frame: "none"`) over the window dimmed to 70% black: one panel (at most 1180x780, zoom-aware) with a 2px `accent` border; a 28px "Mods" title, uppercase INSTALLED / MARKETPLACE tabs with count badges and a 2px `accent` underline; 56px rows with a 34px two-letter monogram tile tinted by kind (installed `done`, local `accent`, built-in `muted`, update `blocked`), the name over a `dim` kind · folder line, and an uppercase status chip (solid "↑ UPDATE" when one is out); a details card with a 56px tile, the name at 20px, uppercase label/value facts and full-width buttons with keycaps; key hints as chips on a `raised` footer strip.

While a tab lives, a `/proc` scan (`reopen.py` `scan`, run when panes, folders, programs or statuses change) finds each Claude or Codex process by its `HC_TERMINAL_ID`: Claude resumes with `--resume <sessionId>` from `<config dir>/sessions/<pid>.json`, in its own `CLAUDE_CONFIG_DIR` and with its own flags (`--continue` without a session file); Codex with `codex resume <id>` from the rollout file it has open (fresh `codex` before its first message); other agents start again; shells come back in their folder. ## Watch out

- **Reopen closed tab**: exact pane trees and sizes need `python3` and `hc connect`. Without them, reopening uses a basic row of panes. Agent session detection reads Linux `/proc` and local session files.
- **Network and programs**: check these before installing.
  - `omarchy-ai-usage` reads login files only at fetch time and never stores tokens:
    - `~/.claude*/.credentials.json`, and on macOS Claude Code's Keychain entry (`security find-generic-password`)
    - `~/.codex/auth.json`
    - `~/.config/github-copilot/*.json`
    - `~/.pi/agent/auth.json`
    - `~/.local/share/opencode/auth.json`
    - `~/.gemini/antigravity-cli/quota-cache.json` (Antigravity's saved quota, no network call)
  - It calls only the providers' own hosts: `api.anthropic.com`, `chatgpt.com`, `api.github.com`. On Linux it reads `/proc/*/environ` to match each terminal to its Claude config directory.
  - `omarchy-spaces` and `omarchy-changes` run `git`.
  - The graph in `omarchy-changes` runs `git`, `find` and `env` (Manygit's fetch-all), and reads files in the repo for diffs.
  - `omarchy-pane` runs `xdg-open` (Linux), `open` (macOS) or `explorer` (Windows) to open links, and `python3` (`pane-size.py`) to keep pane widths. `omarchy-tabs` runs `python3` (`reopen.py`).
  - `omarchy-voice` records the microphone and runs `swiftc` (to build its helper), `whisper-cli`, `ffmpeg`, `hc` and `osascript`; nothing leaves the computer. `omarchy-voice-live` runs `defaults read` and `herdr-app status`.
  - `omarchy-browser` runs herdr-app's `bin/herdr-browser` and its viewer.
  - `omarchy-notes` talks to the local herdr-browser helper (`~/.local/share/herdr-browser`).
  - `omarchy-mod-manager` runs `git`, `gh` (its Marketplace searches GitHub repos tagged `herdr-mod` and `herdr-layout`) and `herdr-app check`.
- **Herdr screen copies**: the palette and Settings copies won't follow Herdr updates to its own screens. Re-copy `frame/palette` and `frame/settings` and reapply `rounded(0)` after a big update.
- **Fixed widths**: a fresh build tends to get these wrong.
  - `bar-left` and `bar-right` share weight 1 each so the usage block (weight 2) stays centered; the right buttons sit at the right end.
  - The usage meter fits about three providers before it truncates.
  - The tab strip assumes 240px cells.
- **Claude account matching**: it is Linux-only and cached per terminal. Elsewhere, both logged-in accounts show.
- **Pi and OpenCode**: they are read from their configured default provider, not the model a running session switched to.
- **Theme names**: if Omarchy itself is installed, its theme switcher writes `themes/omarchy.json` for Herdr. That theme works with this layout, but the layout's default stays `tokyo-night`.
- **Fonts**: the layout sets no font, so the one in `settings.json` applies.
